# Publication requirement

The repository defines canonical IRIs under `chatmangpt.com`, but repository source alone does not make those IRIs dereferenceable.

Promotion from `PARTIAL_ALIVE` requires the domain deployment to serve stable RDF/JSON-LD representations for:

- `/ontology/wasm4pm`
- `/ns/wasm4pm`
- `/ns/wasm4pm/pi`
- `/ns/wasm4pm/cognition`
- `/ns/wasm4pm/trace`
- `/ns/wasm4pm/interview`

Content negotiation and redirects are deployment concerns and are intentionally not asserted as complete by this repository change.
