# docs/internal/

Operational records for the wasm4pm project. These are not user documentation.

| Directory/File | What it contains |
|---|---|
| `audit-history.md` | Chronological log of all doc audits and discrepancies found |
| `REWRITE_MANIFEST.md` | Record of all doc rewrites: what changed and why |
| `audits/` | Per-audit evidence files (validation runs, discrepancy logs) |
| `receipts/` | Kernel receipt records (primitive receipt proofs) |

These files are maintained for project governance, not reader navigation. If you are looking for user-facing documentation, start at [docs/INDEX.md](../INDEX.md).
