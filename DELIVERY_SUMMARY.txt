================================================================================
KEY INSIGHTS
================================================================================

BOTTLENECK 1: WASM Loading (Est. 3-5 seconds)
- Each test file reloads WASM (~2-3s per file)
- 918 files × 2s = 1836 seconds of redundant loading
- Solution: Share WASM instance via singleton pattern

BOTTLENECK 2: Fixture Generation (Est. 2-4 seconds)
- Many tests create identical event logs independently
- 50+ files × 50-100ms = 2500-5000ms of redundant generation
- Solution: Cache generated fixtures in memory

BOTTLENECK 3: Serial Execution (Est. 1-2 seconds overhead)
- Workspaces run sequentially (npm limitation)
- Potential parallelization: 30-40% gain (if workspaces independent)
- Solution: Use background tasks (&) to run workspaces in parallel

BOTTLENECK 4: Slow Tests (Est. 10-15 seconds of 918 tests)
- E2E, integration, ML, and prediction tests are slow (1-3s each)
- ~300+ tests in this category
- Solution: Skip in "fast mode", keep for nightly CI

ROOT CAUSE: Redundant work, not slow algorithms
- WASM doesn't need to reload 918 times
- Logs don't need to regenerate 100+ times
- Workspaces don't need to wait sequentially
