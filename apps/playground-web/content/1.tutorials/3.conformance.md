# Conformance Checking

After discovering a model, **conformance checking** asks: *how well does the model explain the log?*

wasm4pm supports three conformance algorithms:

| Algorithm | Method | Speed |
|-----------|--------|-------|
| `token_replay_conformance` | Token-based replay | Fast |
| `alignment_conformance` | Alignment (optimal edit distance) | Quality |
| `footprint_conformance` | Footprint matrix comparison | Fast |

## Interpreting results

The result JSON includes:
- `fitness` — overall fitness score (0–1)
- `trace_fitness` — per-trace breakdown
- `missing_tokens` / `remaining_tokens` — where the model fails

A model with fitness < 0.85 should be re-discovered or the log re-filtered.

## What if fitness is low?

A fitness score below 0.85 means the model fails to explain a significant portion of the log. Try these steps:

1. **Re-discover with a different algorithm** — Heuristic Miner tolerates noise better than Alpha Miner. Try lowering the `dependency_threshold` (0.2–0.4) to capture more paths.

2. **Filter infrequent variants** — Long-tail variants inflate missing tokens without representing the real process. Use `filter_variants` or `filter_log_variants_percentage` to remove traces below a frequency threshold before re-running conformance.

3. **Check for OCEL vs XES mismatch** — OCEL logs are object-centric; running a flat XES conformance algorithm against an OCEL log produces meaningless fitness scores. Confirm your log format matches the algorithm: `token_replay_conformance` and `alignment_conformance` expect flattened XES; object-centric conformance requires an OCEL-aware algorithm.

4. **Inspect `missing_tokens` hotspots** — High missing token counts on specific transitions indicate the model is missing a path that frequently occurs in the log. Re-examine the discovery parameters or consider splitting the log by case variant.

## MCPP route admission

wasm4pm's manufacturing pipeline requires **exactly 1.0 conformance** for MCPP route admission — no partial fitness allowed. This is stricter than academic standards.
