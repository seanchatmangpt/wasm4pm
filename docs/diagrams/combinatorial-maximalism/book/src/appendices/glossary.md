# Glossary

**Actuation**  
An operation that changes machine or external state.

**Admission**  
The bounded decision that converts an observation into an accepted carrier or a typed refusal.

**Artifact with standing**  
An output whose relevant properties are supported by declared evidence.

**BRCE**  
Brokered Receipt-Carrying Execution. The invariant that all actuation is authorized and receipted.

**CONSTRUCT**  
Reversible graph-domain exploration and candidate manufacture.

**DCM**  
Design for Combinatorial Maximalism: maximize lawful reversible combinations while bounding effects.

**O**  
Observed input before admission.

**O***  
Bounded, canonical, admitted observation.

**Receipt**  
A tamper-evident record binding a decision or effect to its inputs, scope, and predecessor evidence.

**Replay**  
Independent re-derivation or verification. Semantic event replay and cryptographic receipt-chain verification are distinct.

**Standing**  
A typed claim about the evidence status of an artifact or capability.
