# Code of Conduct

We pledge to make participation in wasm4pm harassment-free for everyone.

## Standards

Positive: welcoming language, respect for differing views, graceful criticism acceptance.
Unacceptable: harassment, publishing private information, trolling.

## Enforcement

Report violations to xpointsh@gmail.com. All complaints reviewed promptly.
