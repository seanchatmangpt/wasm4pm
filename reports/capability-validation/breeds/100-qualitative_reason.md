## 4. Expected Semantics

Ground truth semantics are derived from de Kleer-Brown sign algebra:
1. **Sign Representation:** Values are negative (`-`), zero (`0`), or positive (`+`).
2. **Qualitative Addition:**
   - $(+) + (+) = (+)$
   - $(-) + (-) = (-)$
   - $(0) + (x) = (x)$
   - $(+) + (-) = \{+, 0, -\}$ (Ambiguity)
3. **Confluence Solving:** A qualitative state is consistent if it satisfies all confluence equations. For example, $[dp] + [da] - [dq] = 0$ requires that $[dp] + [da]$ matches or contains $[dq]$.
4. **Envisionment:** The state space is generated by iterating through all $3^N$ qualitative sign assignments for the $N$ variables and filtering out states that violate any confluence equations.

In the valve example:
- Equation: $[dp] + [da] - [dq] = 0$.
- Initial signs: $dp = +$, $da = -$.
- Since $(+) + (-) = \{+, 0, -\}$ is ambiguous, $dq$ is unconstrained and can assume any of the 3 signs $\{+, 0, -\}$, yielding exactly 3 consistent qualitative states.
- If $dp = +$, $da = +$, then $(+) + (+) = (+)$, forcing $dq = +$ for the confluence to balance, yielding exactly 1 consistent state.
