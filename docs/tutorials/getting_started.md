# Tutorial: Getting Started with wasm4pm

## Learning Objectives
In this tutorial, you will learn how to:
1. Initialize the `wasm4pm` CLI.
2. Discover your first Petri net from an XES event log.
3. Verify the cryptographic BLAKE3 receipt.

## Step 1: Initialization
Ensure you have the CLI installed:
```bash
wpm --version
```

## Step 2: Discovery
Run the discovery process using the default algorithm:
```bash
wpm run sample.xes
```

## Step 3: Verification
Inspect the cryptographic receipt generated by the run:
```bash
wpm results --verify
```
