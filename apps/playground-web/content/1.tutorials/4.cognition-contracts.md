# Cognition Contracts

The **cognition layer** hosts 9 Old AI breeds — symbolic systems from the 1960s–1990s, restored and running deterministically in WASM. Each breed accepts a structured `intent.json` contract and returns a reproducible result with a BLAKE3 receipt.

## Why Old AI?

LLMs are stochastic. Old AI breeds are **deterministic** — same input always produces the same output, provable by receipt. This matters for manufacturing pipelines where non-determinism is a defect.

## Contract structure

Every breed contract shares this schema:

```json
{
  "breed": "<breed-id>",
  "contract": {
    "intent": "<string>",
    "candidates": [],
    "facts": [{ "key": "...", "value": "..." }],
    "cases": [],
    "rules": [{ "id": "...", "premise": [...], "conclusion": "...", "certainty": 0.9 }],
    "goals": [{ "id": "...", "predicate": "...", "value": "..." }],
    "state": []
  }
}
```

The `breed` field at the top level is **required** — the Rust deserializer uses `deny_unknown_fields` and will reject a bare contract object.
