# Reference: CLI Commands

## Core Commands
`wpm` provides the following top-level operations:

*   `wpm run <file>`: Discover process models.
*   `wpm compare <algos> -i <file>`: Benchmark multiple algorithms.
*   `wpm predict <target> -i <file>`: ML-powered process prediction.
*   `wpm cognition run --contract <name>`: Execute old-AI breeds.

## Global Flags
*   `--profile <name>`: Target execution environment (browser, edge, etc.)
*   `--no-save`: Disable receipt generation.
