## 3. Actual Capability

The PSO capability discovered process models (in DFG format) from event logs by modeling discovery as a metaheuristic search in DFG-space.
- **Inputs:** `eventlog_handle` (&str), `activity_key` (&str), `swarm_size` (usize), and `iterations` (usize).
- **Outputs:** Serialized JSON containing:
  - `handle`: Unique identifier of the discovered `DFG` stored in WASM global state.
  - `algorithm`: String identifier (`"pso_algorithm"`).
  - `nodes`: Number of activities in the discovered DFG.
  - `edges`: Number of directly-follows relationships in the discovered DFG.
  - `final_fitness`: Best fitness score achieved by the swarm.
  - `swarm_size` and `iterations`: Copied parameters.
- **State Touched:** Reads `EventLog` from the global state using `with_event_log` and stores the resulting `DFG` in `StoredObject::DFG` within the global WASM state registry.
- **Error Behavior:**
  - Returns a JS value error `"no_edges"` if `swarm_size < 1`, `iterations == 0`, or the event log contains no directly-follows relationships.
  - Returns `"Failed to store DFG"` if the global state registry allocation fails.
- **Determinism:** Bit-exact reproducibility is ensured by seeding the internal random number generator `StdRng` with a constant seed (`42`).

## 4. Expected Semantics

- **Normal case:** Given a valid, non-empty event log with at least one directly-follows edge (e.g., `running-example.xes`), the algorithm spawns a swarm of size `swarm_size` over `iterations` steps. Each particle updates its personal best and global best by blending position sets with specific weights (0.2 for personal best, 0.3 for global best), mutates edges with a 0.05 probability, and returns the highest fitness DFG.
- **Empty case:** Returns `Err("no_edges")` when the log contains no trace offsets or trace events.
- **Malformed case:** Triggers parsing failure or throws an error before reaching PSO logic.
- **Boundary case:**
  - `swarm_size < 1` -> Returns `Err("no_edges")`.
  - `iterations == 0` -> Returns `Err("no_edges")`.
  - Single event log with no edges -> Returns `Err("no_edges")` because `edge_vocab.is_empty()`.
- **Non-trivial representative case:** A log containing loops and complex paths is evaluated using a columnar memory layout (`ColumnarLog`) to speed up DFG evaluation.
