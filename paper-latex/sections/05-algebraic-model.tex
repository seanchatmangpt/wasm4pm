We map process mining topologies (Petri nets, Process Trees, Reachability Graphs) to advanced algebraic structures, primarily focusing on idempotent semirings and monoids.

Let $\mathcal{G} = (V, E)$ be a process graph. A kernel algorithm defines an algebraic homomorphism:
\[ \Phi : \mathcal{G}_{in} \to \mathcal{G}_{out} \]
Subject to the invariant that the language generated by the graph $\mathcal{L}(\mathcal{G})$ is monotonically restricted or explicitly preserved:
\[ \mathcal{L}(\mathcal{G}_{out}) \subseteq \mathcal{L}(\mathcal{G}_{in}) \]

This structure guarantees that sequence miner capabilities (e.g., A* traversal, prefix alignments) operate within strict combinatorial time $O(|V|^2 + |E|)$, preventing unbounded state explosion.
