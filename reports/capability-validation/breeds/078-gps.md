## 3. Actual Capability

The `Gps` breed in [gps.rs](file:///Users/sac/wasm4pm/crates/wasm4pm-cognition/src/breeds/gps.rs) implements Newell & Simon's (1961/1963) General Problem Solver algorithm based on Means-Ends Analysis and recursive gap reduction.

Key execution details:
- **State and Goals**: State atoms from `input.state` and goals from `input.goals` are represented as `predicate=value` strings.
- **Operators**: Rule id represents the operator name, rule premise contains the preconditions, and conclusion contains semicolon-separated effects (where `!` prefix denotes deletion from state).
- **Means-Ends Gap Selection**:
  - The main loop uses `first_gap` to retrieve the first unsatisfied goal from the goal list.
  - It maintains a `last_gap_count` to ensure that the number of remaining unsatisfied goals strictly decreases after each operator application. If progress stalls or the gap count increases, it aborts with a `"gap not strictly decreasing"` error.
- **Recursive Solver (`solve` method)**:
  - Backed by a depth limit of 32 (`MAX_RECURSION = 32`).
  - Uses a cycle detector: maintains a `visiting` set of active sub-goals. If a sub-goal is re-entered, it throws a `"cycle detected"` error.
  - Matches the current gap to rules whose conclusions explicitly add the goal predicate value.
  - Resolves preconditions recursively: for each precondition of the selected rule, it calls `solve`. If any precondition cannot be satisfied, it rolls back the state using a clone snapshot and tries the next candidate rule.
  - Applies operator effects: deletes negated literals and inserts added literals.
- **Output**: Returns a comma-separated list of operator IDs in `selected` (or `Some("")` for empty/pre-satisfied plans).

## 4. Expected Semantics

The expected behavior of the means-ends planner enforces the Newell & Simon difference reduction logic:
- **Normal case**: For the propositional logic transformation from Fig. 4 of the Newell & Simon RAND paper (initial: `expr=L1`; goal: `expr=L0`), GPS matches the goal to rule `R12` (adds `expr=L0` but requires `expr=L2`). Since `expr=L2` is missing, it sets `expr=L2` as a sub-goal. This matches rule `R6` (adds `expr=L2` requiring `expr=L1`, which is satisfied). It applies `R6`, updating state to `expr=L2`, then applies `R12`, updating state to `expr=L0`, yielding `R6,R12` as the selected plan.
- **Empty/minimal case**: If `goals` or `rules` are empty, preconditions fail and return `Result::Err`.
- **Malformed case**: If action rules are malformed or refer to non-existent state formats, the solver fails during search and returns a `BreedError`.
- **Boundary case**: If goals are already satisfied by the initial state, it short-circuits the search, returns `Some("")`, and logs `check-presatisfied` in the trace.
- **Non-trivial representative case**: Symbolic logic manipulations (connective eliminations or sign changes) that require backtracking over multiple operators to close difference gaps.

* **Recursion Limit**: Reaching a subgoal recursion depth of 32 returns an error, preventing stack overflow.
* **Goal Dependency Cycles**: If solving goal A requires B, and B requires A, the cycle detector catches A in the `visiting` set and backtracks.
* **Infinite Loops (Stalled Gaps)**: The strict gap-decreasing guard catches situations where operators are applied but fail to reduce the remaining goal difference count, raising a `BreedError`.
* **Determinism**: The operator search and backtracking order follow rule declaration order, guaranteeing deterministic plan output and matching BLAKE3 hashes.
