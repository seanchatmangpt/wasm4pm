## 3. Actual Capability

Extracts a Directly Follows Graph (DFG) from an event log (`discover_dfg` in `discovery.rs`). It counts the occurrences of activities (nodes), the start activities, the end activities, and the directly-follows transitions (edges).
- **Actual inputs**: `eventlog_handle` (string handle), `activity_key` (string attribute name).
- **Actual outputs**: A JSON string containing `handle` of the stored DFG, `nodes` count, and `edges` count.
- **Actual state touched**: WASM global thread-local storage (`StoredObject::EventLog` read, `StoredObject::DFG` written).
- **Actual error behavior**: Returns JS error if the log is missing or invalid.
- **Determinism/replay behavior**: Completely deterministic. Uses `BTreeMap` to store and iterate edge counts in a fixed order.

## 4. Expected Semantics

- **Normal case**: For each trace, increments frequency counts of all activities, records the start and end activities, and increments transition counts for adjacent events.
- **Empty/minimal case**: Returns DFG with 0 nodes and 0 edges.
- **Malformed case**: Gracefully skips traces that do not contain the activity key.
- **Boundary case**: Minimal log with 1 event returns 1 node, 0 edges, and start/end activity counts equal to 1.
- **Non-trivial representative case**: Textbook running example log with 5 activities and 8 edges.
