## 3. Actual Capability

The `Asp` breed in [asp.rs](file:///Users/sac/wasm4pm/crates/wasm4pm-cognition/src/breeds/asp.rs) implements stable model semantics for Answer Set Programming (Gelfond & Lifschitz 1988).

Key execution details:
- **Atom Gathering**: Collects all unique atoms from rule conclusions, premises (removing the negation-as-failure prefix `not `), fact keys and values, and candidate IDs.
- **Model Size Cap**: Enforces a strict bound of $\le 16$ unique atoms. If the number of atoms exceeds 16, it throws a `BreedError` to prevent exponential time/memory growth ($2^{16} = 65,536$ interpretations) in the WASM execution loop.
- **Gelfond-Lifschitz Reduct Computation**:
  - Performs an exact search by iterating through all possible interpretations (subsets of atoms) via a bitmask.
  - For each candidate interpretation $I$, it constructs the reduct program $P^I$:
    - Facts from input are added as rules with empty premises.
    - For each input rule, it evaluates premises containing `not <atom>`: if `<atom>` is present in interpretation $I$, the entire rule is discarded. If `<atom>` is absent, the rule is preserved, retaining only its positive premises.
- **Least Model Construction**:
  - Computes the unique least model of the positive reduct program $P^I$ using a fixed-point iteration loop, starting with an empty set and repeatedly applying rules whose positive premises are satisfied.
  - If the computed least model is identical to the candidate interpretation $I$, it is classified as a **stable model** (answer set).
- **Output and Scoring**:
  - Emits the number of stable models via the `stable_models_count` fact.
  - For the first stable model (index 0), it maps the constituent atoms to output facts (`model_0_0`, `model_0_1`, etc.).
  - Scores candidates: if a candidate ID is in the first stable model, its score is updated to `1.0`. The first such candidate is set as `selected`.

## 4. Expected Semantics

The expected behavior verifies stable model generation under negation-as-failure:
- **Normal case**: For the classical choice rule $a \leftarrow \text{not } b$ and $b \leftarrow \text{not } a$, the solver identifies two stable models: $\{a\}$ and $\{b\}$. The count fact `stable_models_count` equals `2`. The first model $\{a\}$ leads to candidate `a` scoring `1.0` and being set as `selected`.
- **Empty/minimal case**: If both `rules` and `facts` are empty, `preconditions` returns an error.
- **Malformed case**: If the negation-as-failure syntax is malformed (e.g. missing space in `nota` instead of `not a`), the atom is treated as a positive literal, shifting the reduct semantics.
- **Boundary case**: A program with no stable models (e.g., $a \leftarrow \text{not } a$) yields `stable_models_count` = `0` and a `None` selection.
- **Non-trivial representative case**: Programs containing both positive rules and negation-as-failure constraints, where the reduct successfully filters out contradiction cycles.
