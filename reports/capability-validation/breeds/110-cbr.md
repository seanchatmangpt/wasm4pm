## 3. Actual Capability
Executes a Case-Based Reasoning (CBR) cycle following the Retrieve, Reuse, Revise, and Retain methodology.

Specifically:
- **Actual Inputs**: A `BreedInput` structure where `input.cases` contains case records (each with a unique ID, intent description, target architecture, outcome score, and list of features as `Fact` objects) and `input.facts` contains query features.
- **Actual Outputs**: A `BreedOutput` structure. `selected` contains the suggested architecture from the matching case. `retained_cases` contains a newly constructed `Case` whose facts are a merged combination of case and query facts. `inference_trace` documents each phase.
- **State Touched**: Stateless outside of Rust's WASM linear memory. All index structures and similarity comparisons reside locally in stack/heap.
- **Error Behavior**: Preconditions verify that `cases` and `facts` lists are not empty, returning `Err(String)` if they are. If no candidate cases share any features with the query, the retrieval phase returns an empty set, and `selected` is `None`.
- **Determinism**: The indexing step constructs a `BTreeMap` mapping string-encoded features (`key=value`) to a sorted `Vec` of case indices. Tie-breaking during best-case selection is done lexicographically by case ID. The retained case ID is generated as a `BLAKE3` hash of the sorted query facts.

## 4. Expected Semantics
Expected behavior model:
- **Normal Case**: The discrimination net retrieves only cases sharing at least one query feature. For each, Jaccard similarity is computed over feature sets. The case with the highest similarity multiplied by its outcome score is selected. The query's features are merged into the case (query overriding conflicts) to construct an adapted case. If the adapted Jaccard similarity to the query is >= 0.5, it is accepted, and a retained case is generated.
- **Empty/Minimal Case**: An empty query or empty case list fails preconditions. A query matching a case exactly yields `sim = 1.0`.
- **Malformed Case**: Facts or case facts containing empty values are processed as features with empty values. Conflicting query keys override case keys during adaptation.
- **Boundary Case**: Zero overlapping features between the query and the case base. The discrimination net returns 0 candidates. The scoring loop is bypassed, `selected` is `None`, and no case is retained.
- **Non-Trivial Representative Case (Physician Vignette)**: The paper fixture `cbr.json` encodes the Aamodt & Plaza physician scenario. The query contains five patient features (medical domain, fever, cough, moderate urgency, current status). The discrimination net filters cases, identifying `CASE-PHYSICIAN-2WK` (which shares 4 features, giving Jaccard 4/6 ≈ 0.667) and `CASE-PHYSICIAN-6MO` (Jaccard 2/8 = 0.25). `CASE-PHYSICIAN-2WK` is selected, adapted to mark the patient status as current, revised as valid, and stored under a deterministic ID.

pub fn jaccard(a: &BTreeSet<String>, b: &BTreeSet<String>) -> f32 {
    if a.is_empty() && b.is_empty() {
        return 0.0;
    }
    let inter = a.intersection(b).count() as f32;
    let union = a.union(b).count() as f32;
    if union == 0.0 {
        0.0
    } else {
        inter / union
    }
}
```

fn build_index(cases: &[Case]) -> BTreeMap<String, Vec<usize>> {
    let mut index: BTreeMap<String, Vec<usize>> = BTreeMap::new();
    for (idx, case) in cases.iter().enumerate() {
        for fact in &case.facts {
            let feature = format!("{}={}", fact.key, fact.value);
            index.entry(feature).or_default().push(idx);
        }
    }
    index
}
```

```rust
fn retrieve_candidates(
    query_features: &BTreeSet<String>,
    index: &BTreeMap<String, Vec<usize>>,
) -> HashSet<usize> {
    if query_features.is_empty() {
        return HashSet::new();
    }

    // Collect all case indices from query features
    let mut candidates: HashSet<usize> = HashSet::new();
    for feature in query_features {
        if let Some(case_ids) = index.get(feature) {
            for &idx in case_ids {
                candidates.insert(idx);
            }
        }
    }
    candidates
}
```
