# Getting Started

**wasm4pm** runs 60 process mining algorithms entirely in your browser via WebAssembly. No server, no install — paste an event log, click **Run**, get a result.

## What you'll learn

- Load an XES event log into the browser WASM runtime
- Run the **Directly-Follows Graph (DFG)** algorithm
- Read the BLAKE3 receipt that proves the computation happened

## Step 1 — Load a sample log

The demo below is pre-loaded with `small-example.xes` — a minimal 4-case event log. Click **Run** to see the DFG:

::AlgorithmDemo{algorithm="simd_streaming_dfg" preset="small-example" label="DFG — small example"}
::

The JSON result shows `nodes` (activities) and `edges` (directly-follows relations). Each edge has a `weight` = the number of times activity A was directly followed by activity B.

## Step 2 — Try a larger log

The Road Traffic Fine Management log has 100 traces. Run the same algorithm on it:

::AlgorithmDemo{algorithm="simd_streaming_dfg" preset="road-traffic" label="DFG — road traffic (100 traces)"}
::

Notice the graph has more nodes and edges — the algorithm scales linearly via SIMD streaming.

## Step 3 — Read the receipt

Every run emits a **BLAKE3 receipt** containing:

| Field | Meaning |
|-------|---------|
| `input_hash` | SHA-256 of the raw XES bytes |
| `output_hash` | SHA-256 of the JSON result |
| `run_id` | Unique UUID for this computation |
| `timestamp` | ISO-8601 wall time |

Switch to the **Receipt** tab after running to inspect it. Receipts are persisted to `localStorage` — the [Sandbox](/play) shows your full history.
