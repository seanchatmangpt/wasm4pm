THE THREE SPANS
================================================================================

SPAN A: rl.convergence_diagnostics
├─ Category: RL Learning Stability (Category B: Policy Improvement)
├─ Oracle Type: Rank-1 (Bellman equation) + Rank-4 (statistical convergence)
├─ Emission: Every 10 cycles
├─ Purpose: Prove RL agent is learning (not stuck or diverging)
├─ Key Attributes: 20+ (TD error, Q-values, weight norms, learning rate)
│  ├─ td_error_mean: average TD error in latest window
│  ├─ td_error_convergence_ratio: should trend toward <1.0
│  ├─ max_q_value: Bellman bound check (should be <100)
│  ├─ max_q_divergence_growth_pct: Q-divergence alarm
│  ├─ linucb_weight_delta_samples: per-agent learning rates
│  └─ reward_mean_window: cumulative reward trend
├─ Jaeger Query: Extract convergence_ratio trend over 100 cycles
│  └─ Expected: early ~0.95-1.0, later <0.8 (proves Rank-4 convergence)
└─ FM-5 Prevention: Include raw TD error samples + computed ratio separately

SPAN B: autonomic.spc_rule_violation
├─ Category: SPC Timeseries Analysis (Category C: SPC Time-Series)
├─ Oracle Type: Rank-1 (Western Electric rules) + Rank-2 (SPC→reward)
├─ Emission: On-demand (when rule fires)
├─ Purpose: Prove SPC detection works, RL reward penalizes violations
├─ Key Attributes: 15+ (z-score, consecutive count, rule metadata)
│  ├─ metric_value: observed metric
│  ├─ control_limit_mean: baseline mean
│  ├─ control_limit_stddev: baseline std dev
│  ├─ z_score: (value - mean) / stddev
│  ├─ rule_violated: rule_1_outlier | rule_2_nine_consecutive | rule_3_monotonic_trend
│  └─ reward_penalty_applied: -0.3 (or -1.5 if multiple)
├─ Jaeger Query: Validate each Rule 1 has |z_score| > 3.0
│  └─ Recompute z independently from attributes, verify match
└─ FM-5 Prevention: Emit all operands (metric, mean, stddev, z_score)

SPAN C: autonomic.circuit_breaker_decision_impact
├─ Category: Circuit Breaker State Machine (Category D: FSM Correctness)
├─ Oracle Type: Rank-2 (FSM correctness) + Rank-3 (metamorphic relation)
├─ Emission: On-demand (on state transition or request blocking)
├─ Purpose: Prove circuit FSM correct, decisions causally impact health/reward
├─ Key Attributes: 18+ (state, timeout operands, decision impact)
│  ├─ current_state_before: Closed | HalfOpen | Open
│  ├─ current_state_after: Closed | HalfOpen | Open
│  ├─ transition_direction: closed_to_open | open_to_halfopen | ...
│  ├─ elapsed_ms_since_state_change: raw timeout measurement
│  ├─ timeout_threshold_ms: raw timeout threshold
│  ├─ timeout_comparison_result: elapsed >= threshold (boolean)
│  ├─ decision_allows_request: boolean outcome
│  └─ request_impact_on_health: improvement | degradation | neutral
├─ Jaeger Query: Validate only legal FSM transitions
│  └─ Extract transition_direction sequence, verify no invalid jumps
└─ FM-5 Prevention: Include all timeout operands, not just result

================================================================================
CHICAGO TDD ORACLE HIERARCHY
================================================================================

Rank-1 Mathematical Theorem
├─ Bellman Equation (RL span): Q(s,a) = R(s,a) + γ max_a' Q(s',a')
├─ Western Electric Rules (SPC span): P(|x-μ| > 3σ) ≈ 0.27%, etc.
└─ Timeout Logic (Circuit span): elapsed >= threshold ⟹ transition allowed

Rank-2 Domain Contract
├─ RL: Stable environment → positive cumulative reward
├─ SPC: Violation → -0.3 reward penalty
└─ Circuit: Closed→Open→HalfOpen→Closed state machine rules

Rank-3 Metamorphic Relation
├─ Health degradation → reward decreases
├─ Open state blocks → health degrades
└─ Recovery success → health improves

Rank-4 Statistical Property
├─ After 50 cycles: mean(reward[last_10]) > mean(reward[first_10])
├─ Convergence ratio trends: 0.95-1.0 (early) → <0.8 (later)
└─ Run 5 seeds: property holds across all random seeds

================================================================================
JAEGER QUERY PATTERNS (EXAMPLES)
================================================================================

RL Convergence Validation (Rank-4):
  service.name:wpm AND span.name:"rl.convergence_diagnostics"
  → Extract [cycle, td_error_convergence_ratio]
  → Plot trend: early ~0.95, later <0.8
  → If convergence trend observed: oracle satisfied ✓

SPC Rule 1 Validation (Rank-1):
  service.name:wpm AND span.name:"autonomic.spc_rule_violation" AND rule_violated:"rule_1_outlier"
  → For each: recompute z = (metric - mean) / stddev
  → Verify: all |z| > 3.0 ✓
  → If any |z| ≤ 3.0: rule fired incorrectly ✗

Circuit FSM Validation (Rank-2):
  service.name:wpm AND span.name:"autonomic.circuit_breaker_decision_impact" AND state_transition_occurred:true
  → Extract [cycle, transition_direction] sorted by cycle ASC
  → Validate: only legal transitions (closed_to_open, open_to_halfopen, ...)
  → If invalid transition found: FSM bug ✗

================================================================================
FM-5 PREVENTION STRATEGY
================================================================================

Problem: Self-referential testing that derives expected values from code logic

Anti-Pattern (BLOCKED):
  Span emits: {z_score: 3.5}
  Test checks: |z_score| > 3.0 ✓
  → Derives z from data, tests z (self-confirming, proves nothing)

Correct Pattern (ENFORCED):
  Span emits: {metric_value: 850.5, control_limit_mean: 420, control_limit_stddev: 120, z_score: 3.58}
  Test checks:
    1. Recompute z_independent = (850.5 - 420) / 120 = 3.58
    2. Verify: z_independent == z_score ✓
    3. Check: |z_independent| > 3.0 ✓ (oracle is external theorem)
  → Oracle (normal distribution) independent of code logic ✓

Implementation in Schema:
  ├─ Required: raw metrics (metric_value, mean, stddev)
  ├─ Computed: derived fields (z_score, convergence_ratio)
  ├─ Oracle: external mathematical theorem
  └─ Validation: Jaeger recomputes, not code-internal
