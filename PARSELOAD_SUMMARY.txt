================================================================================
ROOT CAUSE OF PARSELOAD() === NULL
================================================================================

JSON.parse(result.stdout) THROWS when:

1. result.stdout === '' (empty)
   → JSON.parse('') → SyntaxError: Unexpected end of JSON input
   → catch block → return null

2. result.stdout contains non-JSON (error text, stack trace, etc.)
   → JSON.parse('Error: ...') → SyntaxError: Unexpected token...
   → catch block → return null

3. result.stdout === null or undefined
   → JSON.parse(null) → TypeError
   → catch block → return null

SYMPTOM IN TESTS:
  const payload = parsePayload(result);
  expect(payload).not.toBeNull();  // FAILS: payload === null

IMPLIES: result.stdout is empty or not valid JSON
