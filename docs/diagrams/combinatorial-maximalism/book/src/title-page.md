# Design for Combinatorial Maximalism using all Mermaid

## An Alexander pattern language for proof-carrying manufacturing

**Case study:** `wasm4pm`

**Author:** Sean Chatman

**Edition:** v26.7.24

This book uses every Mermaid 11.16 diagram family as a distinct architectural lens. It does not claim that a diagram is proof. Each pattern states its standing, source grammar, forces, falsifier, and lawful neighbors.

> Maximize reversible construction. Minimize unreceipted actuation. Promote artifacts only when evidence gives them standing.
