FINDING: ⚠️  BREAKING CHANGE — Requires phased rollout with migration period

SUMMARY
━━━━━━
The parsePayload() envelope wrapper changes JSON output shape from:

  OLD (FLAT):  { "schema": "...", "fitness": 0.85, ... }
  NEW (WRAP):  { "payload": { "schema": "...", "fitness": 0.85, ... }, "meta": {...} }

KEY RISKS
━━━━━━━━
1. External scripts will break silently:
   OLD: jq '.fitness' → returns 0.85
   NEW: jq '.fitness' → returns null (no error!)

2. Lab tests will fail on first run post-release (chicken-egg problem)

3. External clients expect flat structure (npm package consumers)

4. Documented API contracts must be updated
