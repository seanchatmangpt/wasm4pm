## 3. Actual Capability

The `Clp` breed in [clp.rs](file:///Users/sac/wasm4pm/crates/wasm4pm-cognition/src/breeds/clp.rs) implements Constraint Logic Programming over finite domains (CLP(FD)) using arc consistency propagation and backtracking search.

Key execution details:
- **Variable Declarations**: Extracts variables from facts using two naming conventions:
  - **Hyphen format**: Key `clp-var` / `csp-var` with value `<name>:<domain>`.
  - **Colon format**: Key `clp:var:<name>` / `csp:var:<name>` with value `<domain>`.
- **Domain Declarations**: Parses domains from strings into a `Vec<String>` of integers:
  - Comma-separated: `1,2,3`.
  - Range: `6..9` (expanded to `6,7,8,9`).
- **Constraint Posting**:
  - Parses arithmetic offsets of the form `x=y+3` or `x=y-3` and binary inequalities (`>=`, `<=`, `!=`, `==`, `<`, `>`, `=`).
  - Converts unary comparisons against integer literals (e.g. `y<4`) into binary constraints by introducing a hidden singleton constant variable `__const_4` with domain `["4"]`.
- **Arc-Consistency Solver**:
  - Leverages the [CspStore](file:///Users/sac/wasm4pm/crates/wasm4pm-cognition/src/breeds/support/csp.rs) module.
  - Implements AC-3 propagation to prune domains.
  - Explores assignments using backtracking search if propagation alone does not resolve the domains.
  - Records execution trace steps: initialization (`clp-init`), domain reductions (`clp-propagate`), arc revisions (`clp-revise`), label assignments (`clp-assign`), backtracks (`clp-backtrack`), and satisfiability outcomes (`clp-verdict`).
- **Output**: Returns `Some("sat")` in `selected` and a sorted list of assigned variables (excluding `__const_` variables) in `explanation`. If UNSAT, returns `None` and `"UNSAT"`.

## 4. Expected Semantics

The expected behavior verifies declarative constraint propagation under the CLP scheme:
- **Normal case**: For the resistive-circuit-style constraint network in the Jaffar & Lassez (1987) paper (variables: $x \in [6..9]$, $y \in [0..9]$; constraints: $x = y + 3$, $y < 4$), propagation of $y < 4$ limits $y$ to $[0..3]$. Propagating $x = y + 3$ updates $x$ to $[3..6]$. The intersection of $x \in [3..6]$ and $x \in [6..9]$ restricts $x$ to $\{6\}$, which propagates back to force $y = 3$. The solver converges on the unique solution $x=6, y=3$ in a single sweep with zero labeling backtracks. Selected output is `sat`.
- **Empty/minimal case**: If no variable decls are found, `preconditions` returns an error.
- **Malformed case**: If constraint expressions contain syntax errors or mention undeclared variables, they are caught during parsing.
- **Boundary case**: Highly constrained systems that fail immediately during initial AC-3 propagation, resulting in an instant UNSAT verdict.
- **Backtrack search**: Under-constrained networks where multiple solutions exist, requiring backtracking search to instantiate variables.
