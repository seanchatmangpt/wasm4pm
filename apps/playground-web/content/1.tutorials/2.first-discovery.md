# First Discovery Run

Process **discovery** converts an event log into a process model. Three algorithms are shown below — each makes different trade-offs between fitness, precision, simplicity, and generalization.

## Alpha Miner

The classic α-algorithm (van der Aalst, 2004). Constructs a Petri net from footprint relations. Fast but cannot handle loops or skips:

## Quality dimensions

| Dimension | What it measures |
|-----------|-----------------|
| **Fitness** | How much of the log the model can replay |
| **Precision** | Whether the model allows behavior not in the log |
| **Simplicity** | Occam's razor — fewer nodes/edges = better |
| **Generalization** | Whether the model generalizes beyond seen traces |
