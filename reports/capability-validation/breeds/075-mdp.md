## 3. Actual Capability

The `Mdp` breed in [mdp.rs](file:///Users/sac/wasm4pm/crates/wasm4pm-cognition/src/breeds/mdp.rs) solves discounted Markov Decision Processes using value iteration and greedy policy extraction. It relies on the [MdpModel](file:///Users/sac/wasm4pm/crates/wasm4pm-cognition/src/breeds/support/mdp.rs) support module.

Key aspects of the implementation:
- **Encoding Formats**: Accepts two inputs:
  - **Implicit format**: Dynamically parses transition relations from facts prefixed with `mdp:trans:<state>:<action>` (yielding value `<next_state>:<probability>` with multiple outcomes split by `;`), and rewards from `mdp:reward:<state>:<action>`. States and actions are collected in first-seen order.
  - **Explicit format**: Reads separate facts named `state`, `action`, `transition` (comma-separated `from,action,to,prob`), and `reward` (comma-separated `state,action,val`).
- **Discount Factor**: Reads `mdp:gamma` (or `gamma`), defaulting to `0.9` if parsing fails. It validates that $0.0 \le \gamma < 1.0$.
- **Validation Constraints**: Implements rigorous checks in `model.validate()`:
  - Probability distributions for each state-action pair must sum to $1.0 \pm 10^{-6}$.
  - State and action indices must be within valid bounds.
  - Every state must have at least one outgoing transition action (no sink/orphan states without actions).
- **Bellman Equation Sweeps**: Performs value iteration updating the state value function:
  $$V_{k+1}(s) = \max_{a} \left[ R(s, a) + \gamma \sum_{s'} P(s' | s, a) V_k(s') \right]$$
  Value updates stop when the max-norm change (residual delta) falls below the threshold $\epsilon (1 - \gamma)/\gamma$ (where $\epsilon = 10^{-4}$), or when sweeps reach the hard cap of 1000.
- **Policy Extraction**: Computes the optimal policy by performing a greedy sweep:
  $$\pi(s) = \arg\max_{a} Q(s, a)$$
  Ties are broken lexicographically using the lowest-indexed action. It outputs the policy as a comma-separated string of `<state>:<action>` pairs in `selected`.

## 4. Expected Semantics

The expected behavior guarantees Bellman optimality is achieved:
- **Normal case**: On a 3-state chain (`s0`, `s1`, `goal`), with $\gamma = 0.9$, `s0` has actions `go` (transits to `s1` with reward 0) and `stay` (transits to `s0` with reward 0.1). `s1` has `go` (transits to `goal` with reward 2.0). The value iteration converges to $V(\text{goal}) = 0.0$, $V(\text{s1}) = 2.0$, and $V(\text{s0}) = 1.8$, showing that the optimal action at `s0` is `go` (maximizing cumulative discount reward over myopic stay). Emits `s0:go,s1:go,goal:stay`.
- **Empty/minimal case**: If state/action data is completely missing and no `mdp:trans:` transitions are declared, preconditions fail and return `Err`.
- **Malformed case**: If transition probabilities for any state-action pair do not sum to $1.0$, `validate()` rejects the model and the run fails.
- **Boundary case**: If $\gamma = 0.0$, the solver acts myopically, resolving in one sweep where values match the immediate rewards.
- **Non-trivial representative case**: Solves cyclic MDP loops where optimal behavior depends on infinite-horizon discounted returns.

## 6. Edge-Case Evidence

The following edge-cases are validated:
* **Orphan States**: States with no defined actions are rejected with a model validation error (returns `"state … has no action"`).
* **Out-of-bound probabilities**: Probabilities $< 0.0$ or $> 1.0$, or sums deviating from $1.0$ by more than $10^{-6}$ are caught and rejected.
* **Gamma boundary**: Rejects $\gamma \ge 1.0$ (returns `"gamma must be in [0,1)"`) which would prevent convergence and cause infinite loops.
* **Deterministic Tie-Breaking**: When multiple actions yield identical Q-values, the first action in lexicographical declaration order is chosen.
* **Myopic limit**: When $\gamma = 0.0$, value iteration converges immediately.
* **Determinism**: Value sweeps are executed in ascending state index order, ensuring bit-exact matching value updates and identical BLAKE3 hashes on repeat runs.
