## 3. Actual Capability

Implements Ant Colony Optimization (ACO) (`discover_aco_algorithm` in `genetic_discovery.rs`) to discover a process model (DFG) from an event log. It maps the log to a DFG by simulating ants walking the graph of directly-follows relationships, depositing pheromones on selected edges.
- **Actual inputs**: `eventlog_handle` (string handle), `activity_key` (string attribute name), `ant_count` (usize number of ants), `iterations` (usize number of generations).
- **Actual outputs**: A serialized JSON string containing `handle`, `"algorithm": "genetic_algorithm"`, `nodes` count, `edges` count, `final_fitness` score, `population_size`, and `generations`.
- **Actual state touched**: WASM global thread-local storage (`StoredObject::EventLog` read, `StoredObject::DFG` written).
- **Actual error behavior**: Returns JS error `"no_edges"` if `ant_count < 1`, `iterations == 0`, or the event log contains no directly-follows edges.
- **Determinism/replay behavior**: Uses a deterministic pseudorandom number generator seeded with 42 (`StdRng::seed_from_u64(42)`) to ensure bit-exact results across executions.

## 4. Expected Semantics

- **Normal case**: Simulates ants choosing edges based on the probability `prob = tau.powf(1.0) * eta.powf(2.0)`. Evaporates pheromones at a rate of 0.1, deposits pheromones based on solution fitness, and clamps pheromones within MAX-MIN Ant System (MMAS) bounds (`[tau_min, tau_max]`).
- **Empty/minimal case**: Refuses logs with no directly-follows edges, returning `"no_edges"`.
- **Malformed case**: Handles malformed parameters (e.g., `ant_count < 1`) by returning `None` (JS error `"no_edges"`).
- **Boundary case**: Single-event trace log returns `"no_edges"` because there are no directly-follows edges to discover.
- **Non-trivial representative case**: Multi-trace log with concurrent activities where pheromone deposits accumulate on dominant paths, pruning noisy/parallel edges.
