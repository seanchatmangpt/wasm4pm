## Profiles

The planner selects algorithms automatically based on the configured profile:

| Profile | Algorithms used | Use case |
|---------|----------------|----------|
| `fast` | DFG, token-replay, footprint | Interactive exploration |
| `balanced` | Heuristic miner, alignment | General use |
| `quality` | Inductive miner, ILP, alignment | High-stakes conformance |
| `stream` | Streaming DFG, concept drift | Live / continuous ingestion |

## WASM API names

Algorithms are called via `discover_<id>`, `conformance_<id>`, or `ml_<id>`. See `WASM_API.md` at repo root for the complete binding catalog.
