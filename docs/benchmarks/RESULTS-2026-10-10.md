# RESULTS-2026-10-10.md

Benchmark run record for v26.10.8 @ main `c48f54b21` (+ working-tree fixes, see
§4), 10 parallel lanes on the canonical checkout (Apple silicon, 16 logical
cores, macOS 25.2.0, Rust stable). Full raw logs:
`.wasm4pm/bench-runs/2026-10-10/` (untracked evidence).

## 0. Dataset provenance note — read before citing any number

At run time `bench_data/sepsis.xes` was a **5-trace / 37-event handcrafted
stub** (D1) and `bpi2020_domestic_declarations.xes` was
**Domestic Declarations** under three names (D2). Both have since been fixed
(639138cd5): the real 1,050-case Sepsis log is restored on disk and the
mislabeled copies were bulk-renamed. So: numbers below tagged `bpi2020` are
grounded on real (mislabeled-at-run-time) event data — the labels changed, the
bytes did not; numbers tagged `sepsis` are grounded on the **synthetic stub**
that was present at run time and are not evidence of real-data performance.
Rerun any sepsis-tagged number before citing it against the real log.

## 1. Lane results

### Lane 1 — `wasm4pm-cognition --bench breed_latency` (Criterion, exit 0)

`rl_symbolic` 1.2305 ms; `hearsay` 213.4 µs; `ilp` 112.6 µs; `pomdp` 91.7 µs;

contingent_plan, autoinstinct_neurosis, default_logic, tableaux, triz,
analogy_sme. Full table: `lane1-breed-latency.log`.

7.1 µs → 6.15 ms, act_r 3.1 µs → 1.35 ms, allen_temporal 2.1 → 6.3 µs,

## 9. ML/prediction API honesty verdicts (commit `0e3d81b38`, landed after the lane run)

The 2026-10-10 lane run measured latency, not predictor honesty. Landing
commit `0e3d81b38` ("feat(ml): real hold-out evaluation for every predictor;
honest metrics") closed the API-honesty findings that the audit surfaced
separately from the bench lanes:

| Finding (pre-`0e3d81b38` state) | Verdict after `0e3d81b38` |
|---|---|
| Advertised 70/30 hold-out for remaining-time/outcome/RF/next-activity did not exist — models were never scored on unseen traces | **Closed.** `ml/evaluation.rs` provides `prefix_split` / k-fold with `MIN_EVAL_SAMPLES = 10`; `build_remaining_time_model_with_eval`, `predict_outcome_evaluated_wasm`, `evaluate_rf_predictor` return real held-out metrics (or `insufficient_data: true`) |
| automl "k-fold" fit each fold on the fold it scored (in-sample metrics) | **Closed.** Real train-complement/test-holdout k-fold (`cv_method: "kfold_train_complement_test_holdout"`); legacy in-sample `results` field deprecated |
| Duplicate unclamped EWMA (`prediction_additions::ewma`) | **Closed.** Deleted; `compute_ewma` is the single clamped EWMA |
| NaN inputs silently poisoned metrics | **Closed.** `ensure_finite_*` typed refusals (`input contains NaN/Inf at index i`) across ml/prediction entry points |
| Drift threshold hard-coded | **Closed.** `detect_drift_with_threshold` (clamped `[0,1]`); default `0.3` unchanged |

Verification at the commit: `cargo test -p wasm4pm --lib` 1229 passed;
holdout-MAE-exceeds-in-sample oracles on noise-injected logs;
insufficient-data refusals below 10 test samples.
